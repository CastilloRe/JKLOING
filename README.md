# 🦉 单词大冒险

一个在浏览器里玩的英语单词学习游戏。纯 HTML/CSS/JavaScript，**不用安装，也不用构建**。

## 快速开始

直接用浏览器打开 `index.html` 就能玩。

如果想用本地服务器运行（推荐，手机也能在同一 Wi-Fi 下访问）：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 玩法

| 模式 | 说明 | 快捷键 |
| --- | --- | --- |
| 🃏 闪卡记忆 | 先看单词，翻开卡片后选择「不认识 / 模糊 / 认识」 | 空格翻卡，1/2/3 评分 |
| ⚡ 极速选择 | 英译中、中译英随机出题，每题限时 12 秒，有 3 条命，连续答对有额外加分 | 1–4 选择，回车下一题 |
| ⌨️ 拼写大师 | 看中文释义和音标，拼出单词，每题可以答两次，可以用提示 | 回车提交 |
| 🎧 听音辨词 | 听发音，选出正确的单词，可以重听或慢速播放 | 1–4 选择，R 重听 |
| 🧩 连连看 | 6 对英汉配对，看谁最快，会记录每个词库的最快成绩 | — |
| 📕 错题复习 | 专门练习答错过、还没掌握的单词 | 1–4 选择 |

所有模式都可以按 `Esc` 退出。

## 特色

- **智能复习（莱特纳盒子）**：每个单词有 0–6 级熟练度。答对升一级，答错退回 1 级。下次什么时候复习由等级决定（当天 / 1 / 2 / 4 / 7 / 15 天后）。出题时先出到期该复习的词，再出新词。熟练度达到 5 级算「已掌握」。
- **成长系统**：有经验值和等级称号，记录连续学习天数，可以设每日目标，还有 10 个成就。
- **3 个内置词库**：小学基础、初中核心、高中/四级，每个 50 词，都带音标、词性、释义和例句。
- **自定义词库**：在「导入词库」里粘贴自己的单词表，每行一个，比如 `curious | adj. 好奇的`。
- **发音**：用浏览器自带的语音合成（Web Speech API）朗读单词和例句。
- **音效、深色模式、手机适配**。
- **离线可用**：学习进度存在浏览器的 localStorage 里。换浏览器或清除网站数据后进度会丢失。

## 项目结构

```
index.html      页面入口
css/style.css   样式（浅色/深色主题）
js/words.js     内置词库数据
js/app.js       游戏逻辑（路由、各玩法、复习算法、成就、存储）
```

## 扩展词库

在 `js/words.js` 的 `WORD_BOOKS` 数组里加一个对象就行：

```js
{
  id: 'cet6',
  name: '六级词汇',
  icon: '🚀',
  desc: 'CET-6 核心词',
  words: [
    ['abstract', '/ˈæbstrækt/', 'adj.', '抽象的', 'Love is an abstract idea.'],
    // [单词, 音标, 词性, 释义, 例句]
  ],
}
```
