# 🦉 单词大冒险

一个在浏览器里玩的英语单词学习游戏。纯 HTML/CSS/JavaScript，**不用安装，也不用构建**。

## 快速开始

直接用浏览器打开 `index.html` 就能玩。

如果想用本地服务器运行（推荐，手机也能在同一 Wi-Fi 下访问）：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 玩法

首页上方是「单词闯关」冒险模式，下面把其余玩法分成三组：学习、练习、游戏。

### ⚔️ 单词闯关

每个词库每 10 个词一关，词数够的话最后还有一个 BOSS 关，题目来自整本词库。进关前可以先看本关的单词。战斗中答对一题就攻击怪物一次，连续答对伤害更高，偶尔会暴击；答错会被怪物反击，3 颗心用完就失败。通关时剩几颗心就得几颗星，通关后解锁下一关。题型在英译中、中译英、例句填空和听音之间随机切换。

### 其他玩法

| 分组 | 模式 | 说明 | 快捷键 |
| --- | --- | --- | --- |
| 学习 | 🃏 闪卡记忆 | 先看单词，翻开卡片后选择「不认识 / 模糊 / 认识」，背面有例句和翻译 | 空格翻卡，1/2/3 评分 |
| 学习 | 📕 错题复习 | 专门练习答错过、还没掌握的单词 | 1–4 选择 |
| 练习 | ⚡ 极速选择 | 英译中、中译英随机出题，每题限时 12 秒，有 3 条命，连续答对有额外加分 | 1–4 选择，回车下一题 |
| 练习 | 🎧 听音辨词 | 听发音，选出正确的单词，可以重听或慢速播放 | 1–4 选择，R 重听 |
| 练习 | ⌨️ 拼写大师 | 看中文释义和音标，拼出单词，每题可以答两次，可以用提示 | 回车提交 |
| 练习 | 🖊️ 听写 | 只听发音写出单词，可以重听、慢速；提示先给中文释义，再给字母 | 回车提交 |
| 练习 | 📝 例句填空 | 看中文句意，选出英文例句空格里的词，答完显示句中的词形变化（如 implemented） | 1–4 选择 |
| 练习 | 🧱 连词成句 | 看中文意思，把打乱的英文单词排成句子；排错时会告诉你前几个词是对的 | 退格撤销 |
| 游戏 | 🔤 字母拼拼 | 点打乱的字母拼出单词，长单词会混入多余字母，手机上不用打字 | 直接按字母键，退格撤销 |
| 游戏 | 🧩 连连看 | 6 对英汉配对，看谁最快，会记录每个词库的最快成绩 | — |
| 游戏 | 🔨 单词打地鼠 | 地鼠举着英文单词冒出来，45 秒内打中意思对的那只；打错了锤子会晕 1 秒 | 1–9 对应九个洞 |
| 游戏 | ⏱️ 60 秒挑战 | 一分钟内答对越多越好，答错扣 3 秒，记录每个词库的最佳成绩 | 1–4 选择 |
| 游戏 | 🌧️ 单词雨 | 中文释义像雨滴一样落下，在落地前打出英文单词；每消除 6 个进入下一波，漏掉 3 个结束 | 直接打字 |

所有模式都可以按 `Esc` 退出。

## 特色

- **智能复习（莱特纳盒子）**：每个单词有 0–6 级熟练度。答对升一级，答错退回 1 级。下次什么时候复习由等级决定（当天 / 1 / 2 / 4 / 7 / 15 天后）。出题时先出到期该复习的词，再出新词。熟练度达到 5 级算「已掌握」。
- **成长系统**：有经验值和等级称号，记录连续学习天数，可以设每日目标，还有 15 个成就。
- **5 个内置词库**：小学基础、初中核心、高中/四级、六级 CET-6、考研英语，每个 50 词，都带音标、词性、释义、例句和例句翻译。
- **自定义词库**：在「导入词库」里粘贴自己的单词表，每行一个，比如 `curious | adj. 好奇的`。导入的词没有例句，所以不能玩例句填空。
- **出题避开近义词**：意思重叠的词（比如 crucial 和 vital）不会同时出现在一道题的选项里。
- **发音**：用浏览器自带的语音合成（Web Speech API）朗读单词和例句。
- **音效、深色模式、手机适配**。
- **离线可用**：学习进度存在浏览器的 localStorage 里。换浏览器或清除网站数据后进度会丢失。

## 项目结构

```
index.html      页面入口
css/style.css   样式（浅色/深色主题）
js/words.js     内置词库数据
js/app.js       游戏逻辑（路由、各玩法、复习算法、成就、存储）
```

## 扩展词库

在 `js/words.js` 的 `WORD_BOOKS` 数组里加一个对象就行：

```js
{
  id: 'ielts',
  name: '雅思词汇',
  icon: '🌍',
  desc: 'IELTS 核心词',
  words: [
    ['coherent', '/kəʊˈhɪərənt/', 'adj.', '连贯的', 'Write a coherent essay.', '写一篇连贯的文章。'],
    // [单词, 音标, 词性, 释义, 例句, 例句翻译]
  ],
}
```
